# MicroSIP — патч Native Call Labels

Это **не** официальный MicroSIP и **не** форк с новой линейкой релизов.  
Репозиторий содержит **патч** к открытому исходному коду softphone MicroSIP версии **3.22.16**.

Все права на оригинальное приложение принадлежат его авторам. Поддерживайте и скачивайте официальные сборки только с сайта разработчика: [microsip.org](https://www.microsip.org/).

## Что меняет патч

1. **Метка аккаунта во входящем звонке** — в окне входящего вызова показывается `label` из `MicroSIP.ini` (`[AccountN] label=`). Если label пустой — `username@domain`.
2. **Отключение проверки обновлений** — чтобы официальный установщик не затёр пропатченный `MicroSIP.exe`.

У MicroSIP нет публичного DLL plugin API для окна входящего звонка, поэтому правятся исходники и нужна пересборка.

Подробности: [`MicroSIP-3.22.16-src-patch/README-RU.md`](MicroSIP-3.22.16-src-patch/README-RU.md).

## Быстрый старт (патч исходников)

1. Скачайте официальные исходники с сайта разработчика (раздел Source).
2. Примените патч:

```powershell
py -3 MicroSIP-3.22.16-src-patch\apply_patch.py "C:\path\to\MicroSIP-src"
```

3. Соберите проект в Visual Studio (MFC + зависимости MicroSIP, в т.ч. PJSIP — в архив исходников не входят).
4. Подмените `MicroSIP.exe` в своей портативной/установленной копии, сохранив `MicroSIP.ini`.

Откат:

```powershell
py -3 MicroSIP-3.22.16-src-patch\apply_patch.py "C:\path\to\MicroSIP-src" --undo
```
